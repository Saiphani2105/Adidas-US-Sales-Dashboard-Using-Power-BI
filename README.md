# Adidas-US-Sales-Dashboard-Using-Power-BI


## 📌 Overview
This Power BI project analyzes retail sales data to uncover trends and insights, helping businesses make informed decisions.

## 📊 Key Insights
1. **Overall Performance Metrics**: Tracks total sales, profit, average price per unit, and total units sold.
2. **Profit Analysis by Retailer**: Identifies top-performing retailers based on total profit.
3. **Sales Trend Over Time**: Monitors sales trends across year, quarter, month, and day.
4. **Product Category Sales Distribution**: Highlights top-selling product categories.
5. **Units Sold by Category & Gender**: Analyzes customer preferences across categories.
6. **Effective Sales Methods Comparison**: Evaluates performance across different sales channels.
7. **Regional Sales Analysis**: Examines variations in sales by region, state, and city.
8. **Top Performing Cities by Profit**: Identifies top 5 cities with the highest profit.

## 🛠 Tools Used
- **Power BI** (Data Visualization)
- **Excel/CSV** (Dataset)
- **DAX & Power Query** (Data Transformation)

## 📁 Files
- `Adida US Sales Report Project.pbix` - Power BI report
- `sales_data.csv` - Dataset
- `README.md` - Project documentation

  
## 🚀 How to Use
1. Download `Retail_Sales_Dashboard.pbix`
2. Open in **Power BI Desktop**
3. Load dataset if needed
4. Explore dashboards & insights
